The game only stays fair while the comms do.

A sighted crewmate who quietly texts an impostor's name to the rest of the team hasn't broken any in-game rule — they've just stepped outside the game entirely. Discord calls, side-channel DMs, and open voice apps turn a ten-player social deduction game into a much smaller, much less interesting one.

Most communities handle this on the honor system, which works until it doesn't — especially once prize pools or rankings are on the line. A.T.S. is built to make that honor system enforceable, without banning voice chat entirely: players still talk freely before and after games, they just lose the side channel for the sixty seconds it actually matters.

How the lock works

Four phases, all tied to the game clock — nothing to remember, nothing for players to toggle themselves.

01 — Pre-lobby

Everyone's comms stay open

Before the host starts the game, voice apps and messaging clients work exactly as normal. A.T.S. only ever activates once a game begins.

02 — Game start

Tasks stay quiet

The instant the host starts the game, every connected player's A.T.S. companion mutes and minimizes flagged voice and messaging apps — same as a normal task phase, there's nothing to say yet.

03 — Discussion phases

Quick chat opens, then closes again

Gathering to discuss opens the host's curated quick-chat set for talk and voting. The moment that ends, quick chat closes and play drops straight back into a locked, silent task phase.

04 — Game end

Everything reopens

The moment the game ends, external comms and free text both return automatically. No manual unlock, no admin needed.

See it in action

The same guard runs on your phone. Setup is one screen: accept the terms, enter your Among Us name. Then it locks down when the game starts and reopens when it ends.

Where A.T.S. actually runs

Built for Windows first. Here's the honest status of everywhere else — no vague "coming soon" badges without a reason attached.

Windows

AVAILABLE NOW

Full support: mutes flagged apps' audio and minimizes their windows automatically.

Download Now

ATS-Guard.exe — if Windows warns the file is unsigned, tap More info, then Run anyway

Linux

AVAILABLE NOW

Same mute + minimize behavior via PulseAudio/PipeWire and xdotool.

Download Now

ATS-Guard-Linux — run chmod +x on it first; needs pactl and xdotool installed

macOS

DETECTION + SYNC ONLY

Finds flagged apps and stays in sync with the host. Per-app audio muting has no equivalent built-in API on macOS yet.

Download Now

ATS-Guard-macOS.zip — unzip it, then right-click the app and choose Open

Android

EXPERIMENTAL

No app can mute another app's audio on Android. Instead, an Accessibility Service detects a flagged app coming to the foreground and sends you straight back to Among Us.

Download Now

ATS-Guard.apk — if Play Protect blocks it, tap More details, then Install anyway. If asked, allow installs from this browser. After installing, turn on A.T.S under Accessibility (on Android 13+: App info, three-dot menu, Allow restricted settings)

iOS

EXPERIMENTAL — SOURCE ONLY

Uses Apple's own Screen Time API to shield chosen apps during the game — the one sanctioned way to do this on iOS, not a workaround.

Download Now

Source code only — an iPhone app needs Apple signing (paid developer account) and Apple's Family Controls approval
